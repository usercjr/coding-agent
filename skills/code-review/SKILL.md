# 代码审查流程

按以下步骤逐项审查目标代码，每条都给出「问题位置 + 为什么 + 建议」：

1. **命名**：变量/函数名是否表意清晰？有没有 `a`、`tmp`、`data2` 这种含糊命名？
2. **边界条件**：空输入、越界、None、空列表/空字符串有没有处理？
3. **错误处理**：可能抛异常的地方有没有兜底？错误是 return 给上层还是直接崩？
4. **重复代码**：有没有复制粘贴、可以抽成函数的重复片段？
5. **资源管理**：文件/连接有没有正确关闭（用 with）？

审查完给一个**总结**：最该先修的 1-2 个问题是什么。
不要直接改代码，只指出问题和建议。
